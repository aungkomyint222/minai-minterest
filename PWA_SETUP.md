## 📝 How to Use

### 1. Run the Development Server
```bash
npm run dev
```

### 2. Test IndexedDB
1. Open the app in your browser
2. Add notes using the form
3. Notes are stored in IndexedDB
4. Refresh the page - notes persist!
5. Open DevTools → Application → IndexedDB to see the database

### 3. Test Offline Mode
1. Open DevTools (F12)
2. Go to Network tab
3. Check "Offline" checkbox
4. The app still works!
5. You can still add/delete notes
6. Badge shows "Offline" status

### 4. Install as PWA
1. Build the production version: `npm run build`
2. Start production server: `npm start`
3. Open in Chrome/Edge
4. Look for install icon in address bar
5. Click to install the app

## 🔧 Important Notes

### PWA Icons
The placeholder icon files were created at:
- `public/icon-192x192.png`
- `public/icon-512x512.png`

**You should replace these with actual PNG images** for the PWA to display properly when installed. You can:
1. Create icons using a tool like [Favicon Generator](https://realfavicongenerator.net/)
2. Use any 192x192 and 512x512 PNG images
3. Replace the empty files in the `public` folder

### Service Worker
The service worker is automatically generated by next-pwa during build. It will be created in the `public` folder:
- `sw.js` - Service worker file
- `workbox-*.js` - Workbox runtime files

These files are generated during `npm run build` and should NOT be committed to git.

### Testing PWA Features
PWA features work best in production mode:
```bash
npm run build
npm start
```

In development mode (`npm run dev`), some PWA features may not work as expected.

## 🐛 Troubleshooting

### Service Worker Not Updating
1. Clear browser cache
2. Unregister old service workers in DevTools → Application → Service Workers
3. Rebuild: `npm run build`

### IndexedDB Not Working
1. Check browser console for errors
2. Verify IndexedDB is enabled in browser settings
3. Clear IndexedDB in DevTools → Application → Storage

### PWA Not Installable
1. Ensure you're using HTTPS or localhost
2. Check manifest.json is accessible
3. Verify icons exist and are valid PNG files
4. Use production build (`npm run build && npm start`)
